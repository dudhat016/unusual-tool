# AetherPix Studio / Unusual Tool — Master Documentation & Route Directory

## Overview
AetherPix Studio (Unusual Tool) is a privacy-first, client-side web application and multi-platform SaaS suite featuring:
1. **Multi-Platform Social Media Mockup Studio** (13 Platforms, 28 Scene Generators).
2. **Standalone Dedicated Tools** (19 Tools across AI, Editing, YouTube, & Developer categories).
3. **Category Suite Landing Hubs** (9 Primary Category Hubs).
4. **High-Performance Image & Audio Format Converters** (In-browser WebAssembly canvas & Web Audio rasterization).
5. **Exact Target KB & MB Compressors** (Parametric Image & PDF compression engines).
6. **Social Media Preset & Pixel Resizers** (Instagram, YouTube, LinkedIn, X/Twitter, TikTok, Facebook, Discord, Pinterest, Threads, Snapchat, Twitch, Tumblr, Spotify, SoundCloud, Reddit, Telegram).
7. **Passport & ID Photo Generator**.
8. **Blog & Editorial CMS**, **SaaS User Dashboard**, and **Admin Management System**.

## 💻 Tech Stack & Key Architecture
- **Frontend**: React 19 + TypeScript 5.8 + Vite 6 + Tailwind CSS v4.
- **Image Rasterization**: `html-to-image` for high-definition 2x scale PNG generation with native `oklch()` color support.
- **Routing & State**: Client-side routing with deep link auto-detection (`getSceneConfigByRoute`).
- **Data Persistence**: Firestore realtime sync + localStorage offline cache.
- **Privacy Standard**: 100% in-browser processing with zero server image storage.
